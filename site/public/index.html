Apps and windows.
Nothing else.

Ciel is a macOS launcher without the bloat. No account, store, plugins, or AI. Press ⌃⌥Space, type a few letters, and press Return.

    Two jobs, done fast

    Finds what you meant

    Prefixes, abbreviations like vsc, typos like safrai, accents, and words in any order, in a few milliseconds. Exact matches always win over history.

    • safraiSafari
    • vscVisual Studio Code
    • calclatorCalculator
    • set sysSystem Settings

    Puts windows where you want them

    Eighteen commands for halves, quarters, three fourths, center, almost maximize, restore, minimize, and moving between displays. Bind any of them to a global shortcut.

    Keeps your Mac to itself

    No server, analytics, or network requests. Preferences and launch history stay on your Mac.

    Nothing you did not ask for

    No store, plugins, account, or AI. One process with no idle timer, and the app list refreshes only when apps change.

    Remembers where you put it

    Drag the launcher and it snaps to guides at each quarter of the screen. Every display keeps its own spot.

    Three keys between you and any app

    1. ⌃⌥Space

      Open Ciel from anywhere

      Control Option Space works over any app. Record a different shortcut in Settings.

    2. saf

      Type a few letters

      Results appear as you type. Tab switches between all results, apps, and window commands.

    3. Return

      Press Return

      Or hold Command and press 1 through 9 to run one of the first nine results.

    Questions

    Is Ciel free?

    Yes. Ciel is free and open source under the MIT license. There is no account, trial, or paid tier.

    Will Ciel get more features?

    Yes, a few. Anything new has to keep Ciel as fast as it is now and stay out of sight until you need it.

    Which Macs does it run on?

    Ciel needs an Apple silicon Mac with macOS 14 Sonoma or later.

    Why does Ciel ask for Accessibility access?

    Only window commands need it, because macOS requires that permission to move and resize other apps' windows. App search works without it. Choose Allow Access in Ciel Settings, then turn Ciel on in Privacy and Security.

    Does Ciel collect any data?

    No. Ciel has no analytics, and its only network request is the speech model download you start in Settings. Dictated audio stays on your Mac. Preferences and launch history are stored in the app.mauriciopolvora.ciel defaults domain, and the app list is cached in your Library folder.

    Can it replace Spotlight?

    Ciel launches apps and runs window commands. It does not search files or the web. To put Ciel on Command Space, turn off the Spotlight shortcut in System Settings first, then record it in Ciel Settings. Ciel keeps your previous shortcut if the new one is taken.

    How does it rank results?

    Exact matches come first. After that, apps and commands you run often move up. That history never leaves your Mac.

    Does it work with full screen apps and Spaces?

    Window commands work on regular windows. Full screen windows and moving windows between Spaces are not supported. When an app enforces a minimum size or refuses a resize, Ciel tells you.

    Can I hide the menu bar icon?

    Yes. Turn off Show menu bar icon in Settings. To get back to Settings later, open the launcher and press Command Comma.

    How do I uninstall it?

    Quit Ciel from its menu bar icon and drag it from Applications to the Trash. To remove its saved settings too, run defaults delete app.mauriciopolvora.ciel in Terminal.

    Can I build it myself?

    Yes. Clone the repository and run bash scripts/build.sh with a Swift 6 toolchain. Apple's Command Line Tools are enough. The README covers installing and signing.
